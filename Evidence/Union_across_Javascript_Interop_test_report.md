## Test Coverage and Required Builds

The source contains equivalent scenarios for all three deployment models:

- `UnionInteropValidation.Server` Blazor Server (Debug/Release/Trimmed)
- `UnionInteropValidation.Standalone` Standalone WebAssembly (Debug/Release/Trimmed/AOT)
- `UnionInteropValidation.Hosted` Hosted WebAssembly (Debug/Release/Trimmed/AOT)

## Release Publish

Command:

```bash
dotnet publish -c Release
```
## Trimmed

Command:

```bash
dotnet publish -c Release -p:PublishTrimmed=true
```

## AOT Publish

Command:

```bash
dotnet publish -c Release -p:RunAOTCompilation=true
```
